# 📊 Data Science Job Market Analysis
 
## 📌 Project Overview
 
This project explores the Data Science job market using SQL-based analysis of vacancy and employer data collected from HeadHunter.
 
The objective is to identify trends in demand for Data Science professionals, salary expectations, required skills, employer activity, and regional distribution of job opportunities.
 
The project relies heavily on SQL queries, data exploration, aggregation, filtering, and analytical reporting.
 
---
 
## 🎯 Project Objectives
 
- Analyze the demand for Data Science specialists
- Explore salary expectations and salary ranges
- Investigate regional distribution of vacancies
- Analyze employer activity and hiring patterns
- Examine required skills and qualifications
- Identify market trends for entry-level and experienced candidates
 
---

The analysis is based on HeadHunter job market data containing:

## 🚀 Installation
 
Clone the repository:
 
```bash
git clone https://github.com/Alex1988Den/Data-Science-Job-Market-Analysis.git
cd Data-Science-Job-Market-Analysis
```
 
Install dependencies:
 
```bash
pip install -r requirements.txt
```
 
Launch Jupyter Notebook:
 
```bash
jupyter notebook
```
 
Open:
 
```text
Data_Science_Job_Market_Analysis.ipynb
```
 
and run all cells.
